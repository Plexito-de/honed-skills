# Governance

honed-skills is maintained by [Plexito](https://plexito.de). The people with write access are
listed in [MAINTAINERS.md](MAINTAINERS.md).

- Maintainers merge pull requests after review. A new skill needs one maintainer approval, a
  passing repository check, and a SkillSpector scan whose findings are fixed or explained.
- A skill is removed when it no longer works and nobody can fix it. The removal is recorded in
  [CHANGELOG.md](CHANGELOG.md).
- Contributors who have made several substantial contributions can be invited as maintainers.
  Ask in an issue.
